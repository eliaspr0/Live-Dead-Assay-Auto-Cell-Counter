live dead assay automatic cell counter deployed on streamlit.

converts image to 8bit color space, applies Otsu's auto threshold, splits into red/green channels and counts live/dead percentage.

based on calcein-am (green - live cells) and ethidium homodimer-1 (red - dead cells)

Features adjustable sliders for min/max cell size value (seperate for live & dead).

https://cellcounter.streamlit.app/
